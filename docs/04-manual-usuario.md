# Manual do Usuário

## 1. Acesso

Acesse a aplicação pelo endereço fornecido pela área responsável.

Na página inicial, escolha uma das opções:

- Registrar incidente;
- Finalizar incidente.

## 2. Registrar um incidente

1. Acesse a opção `Registrar incidente`.
2. Preencha todos os campos obrigatórios.
3. Confira datas, terminal, operadora e demais informações.
4. Clique no botão de execução.
5. Aguarde a conclusão.
6. Confira a mensagem apresentada.

Não feche a página enquanto a execução estiver em andamento.

## 3. Finalizar um incidente

1. Acesse a opção `Finalizar incidente`.
2. Informe os dados do incidente.
3. Confira as informações.
4. Solicite a finalização.
5. Aguarde a conclusão.
6. Confira o resultado apresentado.

## 4. Mensagem de sucesso

Quando a automação informar sucesso, confirme:

- número do chamado;
- status do incidente;
- evidências geradas;
- informações apresentadas na tela.

## 5. Mensagem de erro

Em caso de erro:

1. Não repita imediatamente a operação.
2. Anote o horário da execução.
3. Capture a mensagem apresentada.
4. Verifique se o chamado foi criado ou alterado.
5. Encaminhe as informações ao suporte.

Repetir uma execução sem conferir o estado do chamado pode gerar
duplicidade ou alteração incorreta.
